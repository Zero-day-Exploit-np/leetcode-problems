<h2><a href="https://leetcode.com/problems/build-an-array-with-stack-operations">Build an Array With Stack Operations</a></h2> <img src="https://img.shields.io/badge/Difficulty-Medium-orange" alt="Difficulty: Medium" /> <hr> <p>You are given an integer array <code>target</code> and an integer <code>n</code>.</p> <p>You have an empty stack with the following two operations:</p> <ul> <li><code>"Push"</code>: Pushes an integer to the top of the stack.</li> <li><code>"Pop"</code>: Removes the integer on the top of the stack.</li> </ul> <p>You also have a stream of integers in the range <code>[1, n]</code>.</p> <p>Use the two stack operations to make the numbers in the stack (from bottom to top) equal to <code>target</code>. You must follow these rules:</p> <ul> <li>If the stream is not empty, pick the next integer from the stream and push it onto the stack.</li> <li>If the stack is not empty, you may pop the integer at the top.</li> <li>If at any moment the stack equals <code>target</code>, stop performing operations and stop reading from the stream.</li> </ul> <p>Return the list of stack operations needed to build <code>target</code>. If multiple valid answers exist, return any of them.</p> <p>&nbsp;</p> <p><strong class="example">Example 1:</strong></p> <pre> <strong>Input:</strong> target = [1,3], n = 3 <strong>Output:</strong> ["Push","Push","Pop","Push"] <strong>Explanation:</strong> Start with empty stack. Read 1 → Push → [1] Read 2 → Push → [1,2] Pop → [1] Read 3 → Push → [1,3] </pre> <p><strong class="example">Example 2:</strong></p> <pre> <strong>Input:</strong> target = [1,2,3], n = 3 <strong>Output:</strong> ["Push","Push","Push"] <strong>Explanation:</strong> Read 1 → Push → [1] Read 2 → Push → [1,2] Read 3 → Push → [1,2,3] </pre> <p><strong class="example">Example 3:</strong></p> <pre> <strong>Input:</strong> target = [1,2], n = 4 <strong>Output:</strong> ["Push","Push"] <strong>Explanation:</strong> Read 1 → Push → [1] Read 2 → Push → [1,2] Since stack equals target, stop operations. </pre> <p>&nbsp;</p> <p><strong>Constraints:</strong></p> <ul> <li><code>1 &lt;= target.length &lt;= 100</code></li> <li><code>1 &lt;= n &lt;= 100</code></li> <li><code>1 &lt;= target[i] &lt;= n</code></li> <li><code>target</code> is strictly increasing</li> </ul>
